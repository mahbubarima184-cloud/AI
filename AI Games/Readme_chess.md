♟ Python Chess AI Game
1. Game Overview
This is a classic game of Chess played against a computer opponent. You play as the White pieces, and the AI controls the Black pieces. It uses a strong search algorithm to ensure a challenging experience.
2. How to Run
You need the python-chess library installed to run this game.
A. Installation (One Time)
pip installs python-chess
B. Run the Game
 * Save the code as chess_ai_game.py.
 * Open your terminal or command prompt.
 * Run the file with Python:
Python chess_ai_game.py
3. How to Play
The game uses a standard mouse-click interface:
 * Select: Click on a White piece to select it.
 * Move: Click on a valid square (shown with a green dot) to complete your move.
 * AI Turn: After your move, the AI (Black) will immediately calculate and make its move.
<! -- end list -->
 * Undo Button: Undoes the last two moves (your move + the AI's move).
 * New Game: Resets the board.
4. The AI Algorithm
This game is powered by a standard Artificial Intelligence search method.
 * Algorithm Used: Minimax Search with Alpha-Beta Pruning.
 * Purpose: The algorithm searches several moves ahead to find the best possible move for the Black pieces, trying to maximize its own score while minimizing yours.
